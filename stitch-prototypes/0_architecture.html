State Failure & Recovery: Jika crash terdeteksi saat SIM_RUNNING, status beralih ke CRASHED ➔ RECOVERING ➔ resume ke ronde terakhir via hash SHA-256.
Concurreny Protection: Penguncian siklus hidup graf graph_lifecycle_lock mencegah modifikasi skema ontologi saat simulasi aktif.
Audit Trail WAL: Setiap perpindahan status dicatat secara atomik ke basis data SQLite WAL / PostgreSQL untuk audit transaksional.

backend/app/uploads/
├── projects/<project_id>/              # Partisi Per-Proyek Dokumen & Riset
│   ├── raw_files/                     # Berkas dokumen asli (PDF, MD, TXT)
│   ├── parsed_text.txt                 # Teks hasil ekstraksi & normalisasi
│   ├── project_state.json              # Metadata & status proyek (legacy compat)
│   └── research_cache/                 # Hasil riset Langkah 0 SearXNG
│       ├── query_results.json          # Respon mentah JSON SearXNG
│       └── sanitized_facts.json        # Fakta terverifikasi anti-injeksi
│
├── simulations/<simulation_id>/       # Partisi Eksekusi Swarm 7-Platform
│   ├── simulation_config.json          # Konfigurasi parameter 7 platform & agen
│   ├── agent_profiles.json             # Profil kepribadian OCEAN seluruh agen
│   ├── run_state.json                  # Status eksekusi aktif & metrik per ronde
│   ├── platforms/                      # Partisi log per platform
│   │   ├── twitter/actions.jsonl  ├── x/actions.jsonl  ├── reddit/actions.jsonl
│   │   ├── tiktok/actions.jsonl   ├── instagram/actions.jsonl 
│   │   ├── facebook/actions.jsonl └── threads/actions.jsonl
│   ├── checkpoints/                    # Snapshot integritas ronde & SHA-256
│   │   ├── round_001.snap  ├── round_001.sha256  └── round_N.snap
│   └── ipc/                            # Kanal komunikasi Human-in-the-Loop
│       ├── commands/                   # Perintah masuk (interview, pause, inject)
│       └── responses/                  # Tanggapan agen atas wawancara
│
└── reports/<report_id>/                # Partisi Hasil Analisis ReACT
    ├── agent_log.jsonl                 # Jejak audit ReACT (Thought, Action, Obs)
    ├── sections/                       # Draf teks bab (section_01.md .. section_N.md)
    └── final_report.md                 # Laporan prediksi komprehensif final
